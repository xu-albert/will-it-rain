Gonna Rain? · Release 2 design

A rain timeline for your lock screen

Your idea — a DoorDash / Uber-style progress tracker — translated to weather. Instead of "order → kitchen → on the way," the track is the next ~90 minutes of sky: dry now → rain band → clears, with a live-ticking countdown and a marker that creeps toward the rain. The same anatomy scales down into the Dynamic Island and the widgets.

Now — amber marker, moves left→right in real time Rain band — width = duration, fill = intensity Dry — muted track Cyan — precipitation accent

How it stays live (your "remote push" pick): the app requests a push-to-start token + a per-activity push token and hands them to the Worker. The existing cron already detects rain per grid cell — it gains one job: send an ActivityKit push (apns-push-type: liveactivity) with the new content-state. So the card updates even with the app fully suspended, and the countdown ticks locally in between. Widgets refresh from the shared App Group on WidgetKit's own schedule.
